# Energy_forecast

# SARIMA Model Selection for Time Series Forecasting

Цей проект надає інструменти для прогнозування часових рядів за допомогою SARIMA (Seasonal ARIMA) моделі. Ми здійснюємо пошук оптимальних параметрів моделі на основі оцінки AIC (Akaike Information Criterion) та вибираємо найкращу модель для подальшого прогнозування.

## Опис

1. **Збір та підготовка даних**: 
   - Завантажуються дані з файлу.
   - Додаються додаткові стовпці для місяця та року.

2. **Розкладання на компоненти**:
   - Дані розкладаються на тренд, сезонність та шум за допомогою методу `seasonal_decompose`.

3. **Пошук оптимальних параметрів для SARIMA**:
   - Використовуються різні поєднання параметрів для ARIMA та сезонних параметрів.
   - Для кожної комбінації параметрів розраховується AIC, і модель з найменшим AIC вибирається як найкраща.

4. **Прогнозування**:
   - На основі вибраної моделі здійснюється прогнозування на наступні кроки (на 12 місяців вперед).

5. **Збереження та виведення результатів**:
   - Результати зберігаються у файлі для подальшого аналізу.
   - Виводяться параметри найкращої моделі разом із її AIC.

## Прогнозовані дані

Цей проект призначений для прогнозування виробництва електроенергії в Україні на основі історичних даних за допомогою SARIMA моделі. Дані містять щомісячні показники виробництва електроенергії, і модель прогнозує значення виробництва на наступні місяці (на 2023 рік).

Завдяки розкладу на компоненти (тренд, сезонність, шум) та оптимізації параметрів моделі, ми отримуємо точніші прогнози для планування та аналізу.

Прогнозується значення виробництва електроенергії в мільйонах кіловат-годин (млн кВт·год) для кожного місяця, на основі історичних даних за попередні роки.
